ASUS PRIME Z690-P WIFI D4 — 슬롯 배치

케이스 옆판 열고 봤을 때 방향. 뒷면 I/O 가 왼쪽 · 확장 슬롯이 아래. ASUS 공식 제원 기준 (2026-08-27 확인).

M.2 세 개가 전부 PCIe 4.0 x4 다. SN7100 은 어느 슬롯에 꽂아도 Gen4 최고속이 나온다. 자리 싸움 안 해도 된다 — 제일 손 닿기 쉬운 빈 슬롯에 꽂으면 그만이다.

M.2 슬롯 — 어디에 꽂나

슬롯어디쯤연결쓸까
M.2_1 그래픽카드 바로 위 · CPU 에 가장 가까움 CPU 직결 · PCIe 4.0 ×4 1순위 — CPU 직결이라 부하 걸릴 때 제일 안정적
M.2_2 확장 슬롯들 사이 · 보드 가운데 아래 칩셋 · PCIe 4.0 ×4 2순위 — 속도 같음. 손 닿기 쉬우면 여기
M.2_3 보드 맨 아래 · CMOS 전지 근처 칩셋 · PCIe 4.0 ×4 + SATA 모드 겸용 가능하면 피해라 — SATA 와 얽힐 수 있는 유일한 슬롯
M.2_3 만 조심. 이 슬롯은 SATA 모드도 겸해서, 보드에 따라 여기를 쓰면 SATA 포트 하나가 죽는다. 지금은 SATA 에 아무것도 안 꽂혀 있어서 당장 문제는 없지만, 나중에 HDD 를 달 거라면 새 SSD 를 M.2_1 이나 M.2_2 에 넣어두는 게 뒤탈이 없다.
