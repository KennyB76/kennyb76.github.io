BIOS 확인 — 팬 · 메모리

ASUS PRIME Z690-P WIFI D4 · 2026-08-27 하드웨어 교체 뒤

먼저: Windows 에서 이미 확인된 것 — 메모리 63.8GB · 3200MHz 정상, SSD WD_BLACK SN7100 2TB 인식됨, CPU 정속 3600MHz (펌프 살아 있음). BIOS 는 팬 확인 하나 때문에 들어간다.

들어가는 법

1
재부팅 → 화면 켜지자마자 Delete 연타
2
첫 화면(EZ Mode)에 CPU 온도·메모리가 이미 보인다
3
F7 → Advanced Mode 로 전환
4
맨 위 탭에서 Monitor 선택

팬 헤더 — 0 RPM 찾기

헤더무엇비었으면
AIO_PUMP수랭 펌프즉시 조치
CPU_FANCPU 팬즉시 조치
CPU_OPT보조안 써도 됨
CHA_FAN1케이스 팬급하지 않음
CHA_FAN2케이스 팬급하지 않음
CHA_FAN3케이스 팬급하지 않음
N/A 나 0 RPM 인 줄을 적어라. 그게 빠진 헤더다. AIO_PUMP 와 CPU_FAN 만 살아 있으면 나머지는 오늘 안 고쳐도 된다.

같이 볼 것

CPU 온도 — 40°C 아래면 정상. 70°C 넘으면 펌프 의심
Memory — 65536MB (64GB) · 3200MHz
DIMM 슬롯 — A2·B2 에 32GB 씩 (A1·B1 은 빈칸)
NVMe — 디스크 두 개 다 보이나

손대지 말 것

VMD 관련 항목 전부. Intel RST VMD 가 켜진 채로 Windows 가 깔려 있어서, 끄면 부팅이 안 된다. 저장장치 설정은 건드리지 않는다.

메모리도 이미 3200 으로 돌고 있으니 XMP 손댈 필요 없다.

나올 때

1
아무것도 안 바꿨으면 Esc → Discard Changes & Exit
2
바꿨으면 F10 → Save & Exit
